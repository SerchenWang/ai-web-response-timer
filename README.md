# AI Web Response Timer｜AI 网页总响应计时器

为 ChatGPT、Gemini、DeepSeek 和智谱清言网页端添加可拖动计时面板，估计一次对话从发送到生成结束的总耗时。

当前版本：**1.4.0**。界面及本文档均为中文。

## 安装与下载

首次安装可先阅读 [Windows / Mac 详细安装教程](./安装教程-Windows与Mac-中文.txt)。

- **推荐安装入口：[Greasy Fork 脚本页面](https://greasyfork.org/zh-CN/scripts/601169-ai-web-response-timer-four-platforms)**。
- **仓库文件：[ai-web-response-timer.user.js](./ai-web-response-timer.user.js)**。在文件页面下载原始文件后，使用 Tampermonkey 安装；若浏览器未触发安装，可新建脚本并粘贴文件全部内容保存。
- 通过 Gitee 导入本仓库后，同样可以从 Gitee 的文件页面下载上述脚本。实际访问速度和下载是否需要登录，以平台当前提示为准。

安装前需准备浏览器和 Tampermonkey。主要使用环境是桌面版 Microsoft Edge + Tampermonkey；其他浏览器、脚本管理器和移动端尚未全面验证。

安装新版前请停用旧版，保存后刷新 AI 网站。手动粘贴时不要添加 Markdown 的三个反引号。

## 支持网站

| 网站 | 匹配域名 |
| --- | --- |
| ChatGPT | `chatgpt.com` |
| Gemini | `gemini.google.com` |
| DeepSeek | `chat.deepseek.com` |

## 功能与操作

- 自动识别发送动作或生成状态，启动计时。
- 检测已识别的停止生成控件消失后，自动结束计时。
- 支持手动开始、手动结束和重置。
- 计时中、结束和重置统一显示两位小数，例如 `12.34 s`、`0.00 s`。
- 自动结束或手动结束时播放一次本地短双音，支持开关和试听。
- 默认显示在左上角；拖动面板标题可以移动，也可选择四个角落。
- 在当前网站的浏览器本地存储中记住位置、声音开关和自定义图标特征。
- 内置 DeepSeek、智谱清言的停止图标特征，匹配时无需在新设备首次学习。
- 保留停止图标重新学习功能，以应对网站改版。

“手动结束”和“重置”只操作计时器，不会停止 AI 的回答。重置也不会清除面板位置。刷新或关闭页面会丢失当前计时结果；当前版本不提供历史记录、统计或导出。

## 计时口径

本脚本估计网页端的**总响应耗时**，包含发送后的等待、页面呈现的思考过程及文字输出过程。

开始时间优先参考识别到的发送动作；如果发送动作未识别，但检测到生成状态，则会补启动，这可能遗漏发送到检测之间的时间。

结束时间以已识别的停止生成控件消失为依据。脚本约每 200 毫秒检查一次状态，并等待约 1 秒确认控件持续消失；确认等待时间不计入显示结果。

结果不是服务器处理耗时、首字延迟、精确的最后一个字符呈现时间或模型推理速度。显示到小数点后两位只是显示格式，不代表具备 0.01 秒的测量精度，也不保证误差始终小于 1–2 秒。

## 完成提示音

默认勾选“完成提示音”。更新或首次打开页面后，建议先点击面板中的“试听”，确认浏览器允许发声，再发送消息。正常点击或按键也会尝试启用音频。

- 自动结束或点击“手动结束”时，各播放一次短双音。重复检查不会重复播放。
- 点击“重置”、切换对话导致计时中断时不播放。
- 取消生成或请求失败若触发自动结束，也可能发声；提示音不代表回答成功。
- 取消勾选“完成提示音”即可静音，设置保存在当前网站、当前浏览器中。
- 声音由浏览器 Web Audio API 本地合成，不下载音频、不访问麦克风，也不申请系统通知权限；它不是系统通知音。
- 浏览器自动播放策略、标签页／站点静音、系统音量、输出设备及后台节流都可能使提示音不可闻或延迟。遇到问题请重新勾选并点击“试听”，并检查声音设置。
- 提示音在结束确认后播放，约晚于首次检测到控件消失 1 秒；这段确认等待不计入显示耗时。

音频交互限制可参阅 [Web Audio API 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。

## 改版后的重新学习

此功能适用于 DeepSeek、智谱清言：

1. 发送一个生成时间较长的问题。
2. 生成过程中点击面板的“学习停止图标”。
3. 将鼠标悬停在网页停止按钮的图标中央。
4. 按 **F8** 保存特征，无需点击或右键停止按钮。
5. 等待回答结束，观察计时是否自动结束。

按 **Esc** 可取消学习；部分键盘需按 **Fn + F8**。自定义特征仅保存在当前网站、当前浏览器配置文件中，不会自动跨设备同步。内置特征随脚本文件分发。

## 注意事项与已知限制

- 网站改版、账号界面差异、语言变化或实验性页面可能影响识别。
- 取消生成、请求失败或控件暂时消失可能被判为结束；“自动结束”不代表回答成功或完整。
- 某些未成功提交的发送动作也可能启动计时，请确认网页实际开始生成。
- 后台标签页、最小化窗口、设备休眠及节能机制可能延迟检测，建议测量时保持页面在前台。
- 页面加载时已进行中的回答不会补算此前耗时。
- 刷新、切换对话或离开页面可能中断本轮计时。
- 语音、实时对话、图片／视频生成、复杂工具调用等特殊模式尚未全面验证。
- 用于比较时，请保持提示词、模型、账号条件、联网／思考模式及浏览器环境尽量一致，并进行多次测试。

## 隐私与运行方式

当前版本在浏览器页面内运行，通过检查页面元素、按钮属性和图标特征判断生成状态。

- 不主动提取、保存或上传提示词及回答正文。
- 不读取账号 Cookie 或登录令牌。
- 不拦截、代理或修改网站网络请求。
- 不包含第三方统计、远程代码加载或外部脚本依赖。
- 本地保存面板位置、提示音开关和用户学习的图标特征；计时结果仅保留在当前页面内存中。

以上仅说明本脚本自身的行为，不涵盖网站、浏览器、脚本管理器或其他扩展。卸载脚本不会主动删除网站本地存储中的设置。
