AI 网页总响应计时器：Windows / Mac 新手安装教程
适用脚本：AI Web Response Timer (four platforms)，以 v1.4.0 为例
教程核对日期：2026 年 10 月 20 日

一、先了解需要安装什么

需要完成两次安装：
① 安装 Tampermonkey（篡改猴）浏览器扩展，用来管理和运行脚本。
② 在 Tampermonkey 中安装“AI 网页总响应计时器”脚本。

只安装扩展，不会出现计时面板；只下载脚本文件，也不等于安装成功。
脚本在浏览器网页内运行，不能直接用于 ChatGPT、DeepSeek 等桌面客户端。
它不会提供 AI 网站账号，也不会改变各网站的正常访问和登录条件。

支持的网页域名：
ChatGPT：chatgpt.com
Gemini：gemini.google.com
DeepSeek：chat.deepseek.com
智谱清言：chatglm.cn

二、选择浏览器

Windows 用户：可使用 Microsoft Edge；已经习惯 Chrome 的也可继续使用 Chrome。
Mac 用户：也可使用 Microsoft Edge 或 Chrome，不必因为使用 Mac 就改用 Safari。
本脚本主要使用环境为桌面 Edge + Tampermonkey；Chrome、不同系统版本尚未完成全面兼容性测试。
Safari 有对应版本的 Tampermonkey，但本计时脚本尚未验证 Safari，故不作为本教程的安装路线。

如果需要安装 Edge，请使用微软官网下载适合自己系统的版本：
https://www.microsoft.com/zh-cn/edge/download
Mac 用户选择 macOS 版本，按照安装器提示完成安装；已有浏览器可跳过此步。

后续所有安装、权限设置和 AI 网页测试，都应在同一个浏览器、同一个浏览器个人资料中完成。
例如，在 Edge 装好扩展后，计时器不会自动出现在 Safari 或另一个 Edge 个人资料中。

三、安装 Tampermonkey 扩展

路线 A：Edge（Windows 与 Mac 通用）

1. 打开 Microsoft Edge。
2. 打开 Tampermonkey 官方下载页：
   https://www.tampermonkey.net/index.php?browser=edge&locale=zh
3. 找到普通版“Tampermonkey”，点击“去商店”。本教程不要求安装 BETA 或其他版本。
4. 在 Edge 扩展商店中点击“获取”，查看权限提示后确认“添加扩展”。按钮文字可能随浏览器版本变化。
5. 安装后，点击浏览器右上角的“扩展”拼图图标，找到 Tampermonkey。
6. 如希望方便使用，可选择在工具栏显示该扩展。

官网链接的 Edge 商店入口：
https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd

路线 B：Chrome（Windows 与 Mac 通用）

1. 打开 Google Chrome。
2. 打开 Tampermonkey 官方下载页：
   https://www.tampermonkey.net/index.php?browser=chrome&locale=zh
3. 选择普通版“Tampermonkey”，点击“去商店”。
4. 在 Chrome 应用商店点击“添加至 Chrome”，查看权限提示后确认安装。
5. 点击右上角“扩展”拼图图标，找到 Tampermonkey；可将其固定到工具栏。

官网链接的 Chrome 商店入口：
https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo

若无法访问扩展商店，可以改用本机能够正常访问官方扩展商店的浏览器。Gitee 上的脚本副本不能替代 Tampermonkey 扩展。
公司管理的设备若禁止安装扩展，请联系 IT 管理员；不要绕过公司的设备管理限制。

四、允许 Tampermonkey 运行用户脚本

这一步很重要：扩展已安装、脚本已启用，却没有计时面板时，先检查这里。
以下设置只针对浏览器扩展，不是开启 Windows 开发人员模式，也不是开启 Mac 的系统开发功能。

Chrome：

1. 将 chrome://extensions 复制到地址栏并按回车。请粘贴在最上方地址栏，不是网页搜索框。
2. 找到 Tampermonkey，确认扩展已开启。
3. 点击“详情”或“详细信息”。
4. Chrome 138 及更新版本：找到并开启“允许用户脚本”（Allow user scripts），以当前扩展详情页文字为准。
5. Chrome 138 之前的版本使用扩展管理页的“开发者模式”开关；建议使用浏览器当前支持的新版，不要为安装脚本特意降级。
6. 如果 Tampermonkey 又出现用户脚本相关的权限提示，阅读后按提示允许。

Edge：

1. 将 edge://extensions 复制到地址栏并按回车。
2. 找到 Tampermonkey，确认扩展已开启。
3. 查看扩展“详细信息”和 Tampermonkey 自身的提示。
4. 如果有“允许用户脚本”开关，按提示开启；如没有这个开关，且 Tampermonkey 提示需要开发者模式，则在扩展管理页开启“开发人员模式／开发者模式”。
5. 开关位置与可用选项随 Edge 版本不同可能变化；如果设置后仍提示权限不足，先查看下方官方权限说明，不要执行网上不明来源的控制台命令。

设置完成后刷新 AI 网页；必要时重启浏览器，再重新打开网页。

官方权限说明：
https://www.tampermonkey.net/faq.php?locale=zh&q=Q209
Chrome 官方版本区别说明：
https://developer.chrome.com/docs/extensions/reference/api/userScripts?hl=zh-cn

扩展还需要在相应 AI 网站上运行的站点访问权限。如果浏览器提示“在此网站上允许此扩展”，请针对准备使用的 AI 网站授权。
如扩展详情提供“在特定网站上”选项，可按需添加上述四个域名；实际选项以浏览器提供的权限界面为准。
通过网页安装并运行本脚本，不要求额外开启“允许访问文件网址”，也不要求允许无痕模式。

五、安装 AI 网页总响应计时器

方法一：Greasy Fork 安装（优先使用）

1. 在刚才安装好 Tampermonkey 的浏览器里，打开：
   https://greasyfork.org/zh-CN/scripts/601169-ai-web-response-timer-four-platforms
2. 确认脚本名称为 AI Web Response Timer (four platforms)。
3. 点击“安装此脚本”。
4. 正常情况下，Tampermonkey 会打开安装确认页面。
5. 核对名称和匹配网站，再点击“安装”；如果已有同一脚本，可能显示更新或重新安装。
6. 点击 Tampermonkey 图标，打开“管理面板”，确认列表中有该脚本，并处于启用状态。
7. 打开或刷新 AI 网站。

如果点击安装后只看到一整页代码，或只下载了 .user.js 文件，请使用下面的手动安装方法，不要反复安装多个相同版本。

方法二：从 GitHub、Gitee 或同事提供的文件手动安装

1. 获取完整的 ai-web-response-timer.user.js 文件；文件名可以含版本号，但内容应是完整脚本。
2. 如果收到的是 ZIP，先解压，再找到 .user.js 文件。不要把压缩包、README 或安装教程当成脚本代码。
3. 用能显示纯文本的编辑器打开脚本，或在仓库文件页面查看原始内容（Raw）。
4. 复制全部代码。不要直接双击脚本来运行；不要用 Word 等富文本编辑器改写代码。
5. 点击浏览器右上角 Tampermonkey 图标，选择“添加新脚本／创建新脚本”。也可从管理面板的新建入口进入。
6. 删除编辑器里的全部默认示例代码，再粘贴复制的完整脚本。
7. 检查第一行应为 // ==UserScript==，脚本末尾应完整。不要粘贴开头的三个反引号和 javascript，也不要粘贴结尾的三个反引号。
8. 使用编辑器的“文件 → 保存”或保存按钮。不要把“将网页另存为”当成保存脚本。
9. 返回 Tampermonkey 管理面板，确认脚本已启用；停用旧版计时脚本，只保留一个版本运行。
10. 刷新 AI 网站。

项目仓库地址：
https://github.com/SerchenWang/ai-web-response-timer
仓库中的脚本文件实际上传后，才可从仓库下载；若未找到文件，可使用已发布的 Greasy Fork 页面或维护者提供的脚本文件。
Gitee 下载地址由维护者在仓库导入并验证后提供。本教程不预填尚未确认的 Gitee 地址。

六、首次验证：确认真的安装成功

1. 在安装扩展的同一个浏览器中，打开支持的 AI 官网并正常登录。
2. Windows 可按 Ctrl + R 刷新；Mac 可按 Command + R 刷新。
3. 等待网页加载，左上角应出现带有平台名称、“手动开始”“手动结束”“重置”的计时面板。
4. 发送一个普通文本问题，例如“请用三段话介绍四季的变化”。
5. 观察面板是否进入“计时中”，数字是否增长。
6. 勾选“完成提示音”，点击“试听”并确认能听到声音。回答完成后等待约 1 秒，检查面板是否显示“自动结束”及两位小数的结果，并听到短提示音。
7. 拖动面板顶部标题，或用“位置”菜单换到其他角落；刷新后检查位置是否保留。

完成以上步骤，即可开始日常使用。首次测试不要使用语音、图片生成等特殊模式。
v1.4 已内置 DeepSeek 和智谱清言的停止图标特征；网站界面仍匹配时，不需要每台电脑重新学习。

七、日常操作与计时含义

计时格式：例如 12.34 s；初始和重置均为 0.00 s。两位小数只是显示格式，不代表误差小于 0.01 秒。
完成提示音：默认开启，在自动结束或手动结束时响一次；重置及切换对话导致的中断不响。
首次打开或刷新网页后，建议先点击“试听”，确认浏览器允许播放声音。声音开关会保存在当前网站。
提示音在约 1 秒的结束确认后播放，该确认时间不计入显示结果。
声音由浏览器本地合成，不申请通知或麦克风权限，也不下载音频文件。若听不到，请检查声音开关、试听、站点静音、系统音量和输出设备。后台或休眠时，提示可能延迟或无法播放。取消生成或请求失败也可能触发结束提示音。

自动计时：正常发送消息后，脚本尝试识别发送或生成状态，并在停止生成控件消失后结束。
手动开始：从点击时开始计时。
手动结束：只结束计时，不会停止 AI 回答。
重置：清除当前计时显示，不会停止回答，也不会删除面板位置设置。
移动面板：拖动顶部标题，或选择左上／右上／左下／右下。

显示的是网页端估计的总耗时，包含等待、页面呈现的思考过程和文字输出；不是服务器端耗时或首字延迟。
结束时约 1 秒的确认等待不会计入显示结果，但仍可能存在检测误差，不保证始终小于 1–2 秒。
计时中请保持标签页在前台，避免休眠。刷新、关闭页面或切换对话可能中断计时；当前结果不会作为历史记录保存。
取消生成或请求失败也可能显示“自动结束”，因此它不代表本轮回答一定成功。

八、常见问题排查

1. 安装了 Tampermonkey，仍没有面板

依次检查：
① 扩展是否启用；② 计时脚本是否确实安装且启用；③ 用户脚本执行权限是否已开启；④ 是否允许扩展在当前 AI 网站运行；⑤ 是否已刷新网页；⑥ 是否在相同浏览器、相同个人资料中操作。
如果脚本刚好装在另一个浏览器里，需要在现在使用的浏览器重新安装。
确认打开的是上文列出的网页域名，而不是桌面客户端、其他镜像站或不受支持的入口。

2. 面板显示，但不启动或不结束

先确认只运行一个版本，并使用普通文本对话测试。
DeepSeek／智谱若因改版无法结束，可在生成中点击“学习停止图标”，悬停网页的停止图标中央，按 F8 保存；不要点击停止图标。按 Esc 取消。
Mac 若 F8 被用作媒体键，可尝试 Fn + F8；部分键盘的 Fn 键标有地球图标。Windows 键盘若有多媒体功能，也可能需要 Fn + F8。
如果重新学习仍无效，可暂用“手动结束”，并向维护者反馈。

3. 面板挡住按钮

拖动面板标题，或将位置改为左上角等不遮挡输入框的位置。

4. 下载后出现 .user.js.txt 或没有自动安装

可以直接用纯文本方式打开文件，完整复制内容，按“方法二”手动安装。
计时脚本不需要以 Windows 安装程序或 Mac 应用的方式运行。

5. 安装入口显示“添加至桌面”或无法添加扩展

请确认是在电脑的 Edge／Chrome 中打开对应商店，而不是手机、聊天软件内置网页或另一个浏览器。
若显示“由组织管理”且无法启用，请联系公司 IT；不要尝试绕过限制。

6. 换电脑后是否还要安装

需要在新电脑的目标浏览器中安装 Tampermonkey 和本脚本，或使用经过确认的同步方式。
仅把脚本文件复制到电脑上不会自动生效。便携版内置识别特征，但面板位置和后来学到的自定义特征通常不会随文件一起迁移。

九、更新与停用

从 Greasy Fork 安装的用户，可在 Tampermonkey 中检查更新，或重新访问原发布页安装新版；具体以脚本管理器的更新设置为准。
手动从 GitHub／Gitee 安装的用户，不应默认认为已配置自动更新，应在维护者发布新版后按说明更新。
更新前保留旧文件副本；更新后检查脚本版本，并确保只启用一个计时器版本。

暂时停用：在 Tampermonkey 管理面板关闭该脚本的开关，再刷新 AI 网页。
无需卸载整个 Tampermonkey；同事可能还用它运行其他脚本。

十、权限、隐私与反馈

用户脚本会在匹配的网页内运行，只安装来自可信来源的代码，并核对匹配的网站。
本计时脚本检查页面控件，不主动提取、保存或上传对话正文，不读取 Cookie 或登录令牌，也不监听或修改网络请求。
它会将面板位置、声音开关和自定义图标特征保存在当前网站的浏览器本地存储中。
这些说明仅针对计时脚本本身，Tampermonkey、浏览器和 AI 网站各有独立的隐私政策。

反馈时请提供：Windows／macOS 版本、浏览器名称与版本、Tampermonkey 版本、计时脚本版本、网站名称及具体问题。
截图和错误信息请遮住对话、账号、Cookie、令牌等敏感内容。
